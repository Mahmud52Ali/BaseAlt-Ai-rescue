# Установка

`
apt-get install <ПУТЬ_К_ПАКЕТУ>/alt-ai-rescue-<ВЕРСИЯ>-alt<НОМЕР_РЕЛИЗА>.noarch.rpm
`

**Для установки может потребоваться rpm-пакет llama-cpp**
https://packages.altlinux.org/ru/sisyphus/srpms/llama.cpp/

# Installation

`
apt-get install <PATH_TO_PACKAGE>/alt-ai-rescue-<VERSION>-alt<RELEASE_NUMBER>.noarch.rpm
`

**The llama-cpp rpm package may be required for installation**
https://packages.altlinux.org/ru/sisyphus/srpms/llama.cpp/
